# VetVoice

Ветеринарный справочник и калькулятор дозировок с голосовым управлением.

## Функции

- **Калькулятор дозировок** — расчёт дозы по весу, концентрации и виду животного (2400+ препаратов)
- **Голосовое управление** — поиск препаратов и навигация голосом
- **Противопоказания при беременности** — по каждому виду животного отдельно
- **Каренція (выжидательные периоды)** — по продукциям (молоко, мясо, яйца)
- **Лекарственные взаимодействия** — совместимость препаратов
- **Экстренные протоколы** — инструкции при отравлениях и экстренных состояниях
- **Антидоты** — подбор антидотов по токсину
- **Жидкостная терапия** — расчёт объёмов и составов
- **Неофициальные протоколы** — схемы лечения от практикующих ветеринаров
- **Болезни** — справочник заболеваний по видам

## Поддерживаемые виды

КРС, МРС, Свиньи, Лошади, Собаки, Кошки, Кролики, Пушные звери, Птица, Пчёлы

│       ├── emergency_protocols.json     # Экстренные протоколы
│       ├── antidotes.json               # Антидоты
│       ├── fluid_therapy.json           # Жидкостная терапия

├── lib/
│   ├── screens/
│   │   ├── home_screen.dart             # Главный экран
│   │   ├── diseases_screen.dart         # Болезни
│   │   ├── fluid_therapy_screen.dart    # Жидкостная терапия
│   │   └── unofficial_protocols_screen.dart  # Неофициальные протоколы
│   ├── models/
│   │   └── calc_drug.dart               # Модели данных препаратов
│   ├── providers/

│   ├── services/                        # Сервисы (голос, поиск)

## Технологии

- **Flutter** — кроссплатформенный UI
- **Dart** — язык разработки
- **JSON** — формат хранения данных (без серверной БД)
